# student/ — Start Here

**You are in the right place if you have never programmed before.** This
folder is your map to everything student-facing in the repository.

## Your first 30 minutes

1. Install a compiler for your operating system — follow
   [../docs/TOOLCHAIN.md](../docs/TOOLCHAIN.md) exactly (Windows · macOS ·
   Linux sections, ~15 min).
2. Build and run your first program — the same doc, § 4–5 (~10 min).
3. Read the [glossary](../resources/glossary.md) "Week 1" terms (~5 min) —
   these words will be used in lecture 1.

## Expectation setting (read once, believe it)

Programming is learned by *typing, breaking, and fixing*, not by watching.
Expect compiler errors daily in week 1 — they are normal, they are the
curriculum, and reading them is skill PF-A3
([../LEARNING_OUTCOMES.md](../LEARNING_OUTCOMES.md)). If you are stuck more
than 30 minutes on one error, stop and get help — that is the efficient move,
not a failure.
