# quizzes/ — Module Quizzes (Student-Facing Questions)

Sixteen 15-minute module quizzes, one per module, run in week *n*'s second
lecture. 10 marks each; **lowest two dropped** — quizzes are **15 %** of the
course grade (see [../instructor/assessment-rubrics/README.md](../instructor/assessment-rubrics/README.md)
§ Course-wide grading distribution).

Each `quiz_NN/` holds `quiz.md` (the student paper — 7 items: 4 MCQ, 1 trace,
1 debug, 1 short; 10 marks) and `instructor_key.md` (**restricted**, banner on
every key; see [../instructor/ACCESS_CONTROL.md](../instructor/ACCESS_CONTROL.md)).

Item types per quiz: MCQ (concept), output tracing (mechanism), debugging
(diagnosis), short conceptual (vocabulary/design). All tracing answers were
machine-verified; see `../docs/ASSESSMENT_AUDIT.md`.
