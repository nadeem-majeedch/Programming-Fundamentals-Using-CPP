# Exam Bank — Question Pools for the Midterm and Final
**INSTRUCTOR-ONLY** per [../../instructor/ACCESS_CONTROL.md](../../instructor/ACCESS_CONTROL.md).

Two pools supply every paper:

* `midterm_bank.md` — 42 items covering Weeks 1–8 (L01–L16) · 94 pool marks.
* `final_bank.md` — 48 items covering all 16 modules (emphasis 9–16, per the weighting table inside) · 112 pool marks.

Every item is tagged: type, module, lecture, CLO, difficulty (E/M/H), marks, and
machine-verified expected output (tracing/coding items were executed with GCC 16.2
under the course contract — see the verification table at the end of each bank).

Assembly rules, blueprint tables, and printing checklists live in
[`PAPER_ASSEMBLY.md`](PAPER_ASSEMBLY.md). Papers built from these pools:
`midterm_form_A.md` … `midterm_form_D.md`, `final_form_A.md` … `final_form_D.md`.

**Security:** rotate forms between sittings; never return marked question booklets.
