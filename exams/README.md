# exams/ — Examination Hub (Student-Facing)

This directory holds the **student-facing** exam information: review guides and
the practical assessment overview. Question papers and answer keys are
instructor-only and live under `instructor/exams/` — never published here.

| Path | Purpose |
|---|---|
| [midterm/review_guide.md](midterm/review_guide.md) | What the midterm covers, skills table, drills, technique |
| [final/review_guide.md](final/review_guide.md) | Final emphasis map (M9–M16), complexity facts, drills |
| [practical/README.md](practical/README.md) | 2-hour lab exam format, rules, grading |

## Exam schedule (per course plan)

- **Midterm** — Week 9, first lecture slot (covers Weeks 1–8).
- **Practical** — Week 16, lab slot.
- **Final** — exam period (covers all 16 modules, ≥ 60 % weight on M9–M16).

Forms A–D exist for both papers for rotation security; students see only the
assembled form handed out on the day. Nothing in this directory reveals which
items any form contains.
