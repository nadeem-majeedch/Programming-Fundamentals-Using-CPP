# resources/ — Curated References & Tools

Everything external a student needs, in one place. **Policy: only real,
verified, freely accessible sources are listed** — no invented references
([../CONTRIBUTING.md](../CONTRIBUTING.md) § 5).

## Documentation (authoritative)

| Resource | URL | Use it for |
|---|---|---|
| cppreference | <https://en.cppreference.com/> | language & library reference (the course's citation of record) |
| C++ Core Guidelines | <https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines> | "why" behind style rules |
| isocpp.org standard status | <https://isocpp.org/std/status> | which standard is which |
| Compiler support (cppreference) | <https://en.cppreference.com/w/cpp/compiler_support> | feature availability per compiler |
