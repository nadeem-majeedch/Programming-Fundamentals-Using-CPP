# cheat_sheets/ — One-Page Syntax Sheets

Quick-reference sheets students may use while practicing (not in exams unless
the instructor says so). Authored as the course content lands
([../../docs/CONTENT_ROADMAP.md](../../docs/CONTENT_ROADMAP.md) § 3 step 6).

## Planned sheets

| Sheet | Coverage | Status |
|---|---|---|
| `cpp_basics.md` | program shape, `cout`/`cin`, types | ⏳ |
| `control_flow.md` | `if/else`, `switch`, all loop forms | ⏳ |
| `functions.md` | signatures, overloads, references | ⏳ |
| `collections.md` | arrays, `vector`, `string` operations | ⏳ |
| `structs_files.md` | `struct`, `ifstream`/`ofstream` | ⏳ |

## Rules

- One page each (fits a printed A4), tables over prose, no long examples.
- Every construct matches the taught subset
  ([../../docs/CPP_STANDARD.md](../../docs/CPP_STANDARD.md) § 4).
