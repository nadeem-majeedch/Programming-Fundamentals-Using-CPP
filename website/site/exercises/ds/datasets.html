DS Datasets

All datasets are student-visible and may be freely copied. Every dataset that contains defects documents them here, together with the expected values a correct program must produce — so students can self-check and graders compare.

Generated inputs are also welcome; when a task says "use the dataset", use these files so outputs are comparable.
