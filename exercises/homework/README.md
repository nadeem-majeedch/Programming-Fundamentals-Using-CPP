# homework/ — Weekly Practice Problems

Self-checked practice (3–5 problems/week) that prepares for graded
[../../assignments/](../../assignments/README.md). Not graded directly;
consistency is what the drop-lowest assignment policy assumes.

- Sets: `week_NN_topic.md` — authored per week-batch
  ([../../docs/CONTENT_ROADMAP.md](../../docs/CONTENT_ROADMAP.md) § 3).
- Solutions: [`solutions/`](solutions/README.md) — published after the due
  date of the related assignment.
