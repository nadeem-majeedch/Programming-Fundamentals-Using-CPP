# lab_manuals/ — Per-Lab Folders

One folder per lab: `lab_01/ … lab_07/` (weeks 2, 4, 6, 8, 10, 12, 15 — see
[../README.md](../README.md) § Lab plan).

Each lab folder will contain:

- `manual.md` — student manual (tasks, checkpoints, submission)
- `starter_code/` — optional skeletons (compile contract applies)
- `instructor_notes/` — TA checklist (restricted)

⏳ Authored per [../../docs/CONTENT_ROADMAP.md](../../docs/CONTENT_ROADMAP.md),
Lab 1 first — content is specified by the matching lecture planning files
(L04, L08, L12, L16, L20, L24, L30).
