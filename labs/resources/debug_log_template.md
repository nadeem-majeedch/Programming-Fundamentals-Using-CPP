**Student:** {name} · **ID:** {id}

One block per defect. The grade pays for the *diagnosis*, not the fix.

## Defect 1

1. **Reproduce:** exact input/command that triggers it.
2. **Symptom:** what happens (error text, wrong output, hang).
3. **Isolate:** smallest input/code region that still shows it.
4. **Stage:** compile / link / runtime / logic.
5. **Hypothesis:** what you believed caused it.
6. **Test of hypothesis:** what you changed/checked to confirm.
7. **Fix and verify:** the change + the rerun that proves it fixed.
